这项分析能说明什么

可比较固定道路网络和设施记录下，不同步行速度及设施关闭情景的空间差异。采样网格不是人口数据；点位覆盖比例不能称作居民覆盖率。

未核验设施营业、入口与服务能力；设施类型分开计算，不代表可相互替代。未建模坡度、红绿灯等待、开放时间、条件通行限制或转向限制。关闭情景只去掉一个设施的目标节点，不关闭道路。没有实测步行时间真值，不能声称导航精度或医疗服务可获得性。
