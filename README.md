# CityAccess

**用真实道路拓扑计算设施可达性。** Oxford / OpenStreetMap / NetworkX / Shapely / PyProj。

[交互演示](https://clnay5.github.io/cityaccess/) · [方法与限制](METHOD.md) · [真实核验](evidence/validation.json) · [数据授权](DATA_LICENSE.md)

## 实现内容

- 公开 OSM 道路与四类医疗设施记录；保存精确查询、原始快照、时间及 SHA-256。
- EPSG:32630 米制建图，步行权限与方向规则，多个连通分量，桥梁图面相交不误连。
- STRtree 最近道路边、边内拆分、100 m 连接距离上限；连接距离计入路程。
- 反向图多源最短路、3 / 4.8 / 6 km/h 速度情景、移除一处设施的情景复算。
- 可点击采样点地图、真实模型路线、缺失提示及 GeoJSON 导出。

## 离线运行

Python 3.11+：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -e ".[test]"
python -m pytest -q
python -m cityaccess.pipeline
python scripts/verify_results.py
python -m http.server 4176 --directory docs
```

访问 `http://127.0.0.1:4176/`。已提交压缩的原始数据快照，复算不联网。刷新 OSM 数据可执行 `python scripts/download_osm.py`，公共服务可能拒绝或超时；脚本带项目 User-Agent，不做频繁查询。先保留旧快照，再刷新，避免混淆不同日期结果。

## 真实案例

2026‑10‑25 的公开 OSM 快照，原始约 5.33 MB / 41,263 元素。道路缓冲区大于分析区：

| 项目 | 数值 |
|---|---:|
| 原生道路段 | 24,877 |
| 图节点 / 有向边 | 22,820 / 50,283 |
| 弱连通分量 | 116 |
| 全部 / 成功连接采样点 | 117 / 111 |
| 多源与逐点最短路数值核对 | 80 组一致 |

基线速度 4.8 km/h 下，药房记录的 15 分钟采样点比例为 **96/117 ≈82.1%**，医生诊所 **90/117 ≈76.9%**，Clinic **101/117 ≈86.3%**。这些是空间采样点，不是人口覆盖率。提取区内无可连接医院记录，显示“无法评估”，不能据此断言牛津没有医院。

## 解释与质量边界

设施来源是 OSM 记录，未核验入口、营业与医疗服务能力；医院、药房、诊所分开计算。采样点均匀覆盖空间，未排除河流或非住宅地物；这反映道路与设施的空间关系，不代表居民需求。连接边可能跨越围墙或私人用地；未建模开放时间、条件限制、坡度、交通信号或实测步行速度，不能用于医疗导航决策。

测试覆盖权限、方向、边内吸附、虚假交叉、并行边及不可连接情况。真实数据还核对多源/逐点算法、路径成本、直线下界、速度和关闭情景单调性；这些是数值一致性验证，不是实地路线精度验证。CI 在 Linux / Windows 从原始快照重算。

## 简历与面试

实际复跑并理解后，可据实写：

> 开发 CityAccess 设施可达性分析工具，将真实 OSM 数据构建为 5 万余条有向边的步行网络，实现权限筛选、边内吸附、多源最短路及速度/设施关闭情景；完成 80 组独立最短路数值核验，并提供交互地图与可复现数据快照。

AI 辅助开发。面试应能解释有向图为什么反转、边内吸附如何避免顶点绕行、桥梁为何不能仅凭几何交叉连通、采样点比例与人口覆盖率的区别，以及入口未知如何影响路径。未将已有项目改名冒充原创；经典方法与依赖见 METHOD。
